RSS 的局限

RSS 并不是万能的数据来源。不同网站提供的信息完整度差异很大，有些只有标题和链接，有些提供摘要甚至全文，还有一些网站完全不提供 RSS。因此实际的信息采集通常会同时使用多种方式：

有 RSS 时优先使用 RSS，因为它通常比直接抓取 HTML 更稳定；没有 RSS 时，再考虑 API 或专门的网页采集器。

总结

RSS 本质上就是：

网站为程序提供的“最新内容清单”。

它把网页内容转换成统一、结构化的数据，使程序能够低成本地持续获取多个网站的最新更新。对于新闻聚合、技术资讯订阅和内容监控这类场景，RSS 仍然是一种简单而实用的数据来源。
