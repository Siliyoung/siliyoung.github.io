最近把一个原本运行在微信小程序里的项目迁移成了 Web/PWA 版本，前端使用 Vue 3 + Vite。后端仍然运行在自己的服务器上，前端则希望找一个不需要额外维护 Nginx、支持 HTTPS、还能自动跟 GitHub 同步的平台。最后选择了 Cloudflare Pages。

实际用下来，这套流程非常适合个人项目：代码推到 GitHub，Cloudflare 自动拉取、构建、部署，之后每次更新 main 分支都可以自动发布。

这套部署方式适合什么项目

折腾完之后，会发现 Cloudflare Pages 并不是什么复杂的“云原生部署平台”，如果只是从个人开发角度理解，可以把它看成：

GitHub 仓库的自动构建 + 静态网站托管 + CDN + HTTPS。

对于：

Vue、React、Vite、个人博客、文档站、PWA、项目官网

都很合适。这次迁移之后，整个项目也变成了比较清晰的结构：

前端更新交给 GitHub + Cloudflare，后端继续运行在自己的服务器上，两边互不影响。

相比把所有东西都部署在一台服务器上，这种方式最大的感受不是“性能提升了多少”，而是前端部署变得非常省心：提交代码之后，剩下的事情基本都由 Cloudflare 自动完成。
